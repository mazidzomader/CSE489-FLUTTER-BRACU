AI Usage Justification

In this project, AI was used primarily in a pair-programming context to architect the UI and fix errors. 

Specific AI Usage:
1. UI Generation: Standard Material 3 templates for the Bottom Navigation shell and basic ListViews were generated by the AI to save time, allowing more focus on the core business logic (offline sync and API interactions).
2. Troubleshooting: The AI was consulted to fix an inline import syntax error .
