# AI-Assisted Software Engineering — Resource Notes

A curated set of links shared around the theme of how AI is reshaping who builds software, how they build it, and what tools/communities are forming around that shift — with a focus on the Bangladesh dev scene.

## Learning Resources

- **[মন্টু মিয়াঁর সিস্টেম ডিজাইন (Montumia)](https://www.montumia.com/)**
  A Bengali-language system design book by Shakirul Hasan Khan, teaching core system design concepts (scaling, load balancers, etc.) through a story-driven, analogy-based narrative. Open-sourced on [GitHub](https://github.com/KhanShaheb34/montu-mia).

## Competitions & Events

- **[Kotlin Shipaton 2026 — Ship Kotlin Everywhere Award](https://kotlinlang.org/lp/shipaton/)**
  JetBrains/Kotlin competition encouraging developers to reuse Kotlin skills across Android, iOS, desktop, and web via Kotlin Multiplatform.

- **[Swift Guild — The AI-Powered iOS Developer (Shunnek Labs)](https://www.shunneklabs.com/events/swift-guild-ai-powered-ios-developer-swiftui-2026)**
  A Bangla-language meetup (Fri, 17 Jul 2026) on using AI as a practical assistant across the iOS dev lifecycle — planning apps, writing cleaner SwiftUI, debugging faster, and prepping for App Store submission. Talk by Khandker Mahmudur Rahman. Workshop resources available via Google Drive; recap materials linked on the event page.

## Notable / Adjacent

- **[Ghush.site](https://www.ghush.site/)**
  An anonymous, account-free public ledger for reporting bribes ("ঘুষ") demanded at government offices across Bangladesh. No identity fields, no IP logging, cookie-free analytics — reports are moderated before going public and aggregated into per-region and per-office patterns. Interesting as a civic-tech / transparency project example, and as a build worth studying from a product/engineering standpoint.
